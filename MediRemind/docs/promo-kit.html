약 먹을 시간, 놓치지 않게. 놓치면 가족이 알게.

매일 약을 챙겨야 하는 사람을 위한 복약 알림 앱입니다. 광고 없이 기기 안에서 조용히 동작하고, 1.2부터는 부모님이 약을 놓치면 자녀에게 알림이 갑니다.

문제와 해결

왜 필요한가

  • 문제

    "먹었나, 안 먹었나" 기억이 안 난다

    하루 여러 번, 여러 종류의 약을 먹다 보면 방금 먹었는지 헷갈립니다.

  • 문제

    멀리 사는 부모님이 걱정된다

    전화로 매번 "약 드셨어요?" 묻기는 어렵고, 부모님도 부담스러워합니다.

  • 문제

    복약 앱은 광고투성이거나 가입이 복잡하다

    어르신에게 회원가입·광고 팝업은 그 자체로 진입 장벽입니다.

  • 해결

    알림 한 번, 체크 한 번, 놓치면 가족에게

    가입 없이 바로 쓰고, 알림에서 바로 "복용 완료"를 누르고, 놓치면 연결된 가족이 압니다.

신규 · 1.2.0 · 테스트 중

보호자 연결 (가족 알림)

부모님이 약 시간에서 30분이 지나도 체크하지 않으면 자녀 폰으로 "엄마님이 08:00 혈압약을 아직 복용하지 않았어요" 알림이 갑니다. 자녀는 앱에서 부모님의 오늘 복용 현황(복용·예정·확인 중·안 먹음)을 바로 볼 수 있습니다.

1. 부모님 폰설정 → 보호자 연결 → 초대 코드 만들기
2. 자녀 폰같은 앱에서 6자리 코드 입력 → 연결
3. 놓치면30분 뒤 자녀에게 알림, 한 번만

이름·이메일 없는 익명 연결. 약 이름과 복용 시간·여부만 연결된 가족에게 공유되고, 언제든 연결 해제와 서버 데이터 삭제가 가능합니다.

  • 1.1.0

    시간대별 복약 알림

    하루 최대 20회, 요일 지정(매일·평일·주말·직접 선택), 복용 몇 분 전 미리 알림. 같은 시간 약은 한 알림으로 묶어 보냅니다.

  • 1.1.0

    알림에서 바로 "복용 완료"

    앱을 열지 않고 알림의 버튼으로 체크합니다.

  • 1.1.0

    자유로운 용량 입력

    0.5정부터 10정까지 빠른 선택, 직접 입력(정·캡슐·포·mg·mL).

  • 1.1.0

    복용 달력과 연속 복용 기록

    날짜별 복용 기록과 며칠째 빠짐없이 먹었는지 보여 주는 연속 기록.

  • 1.1.0

    처방 기간과 재처방 알림

    처방이 끝나기 며칠 전에 병원 갈 때를 알려 줍니다.

  • 1.1.0

    백업과 복원

    새 폰으로 바꿔도 파일 하나로 약과 기록을 옮깁니다.

  • 1.1.0

    다크 모드 · 한국어/영어

    시스템 설정을 따라가고, 언어는 앱에서 바로 바꿉니다.

  • 1.1.0

    알림 꺼짐 경고와 알림 테스트

    iPhone 설정에서 알림이 꺼져 있으면 홈 화면에서 바로 알려 주고, 설정에서 테스트 알림을 보내 볼 수 있습니다.

1.1.0은 App Store 심사 중, 1.2.0(보호자 연결)은 TestFlight 테스트 중입니다. 홍보물에는 출시된 기능만 "지금 사용 가능"으로 표기해 주세요.

믿고 쓸 수 있는 이유

  • 개인정보

    기본 기능은 아무것도 수집하지 않습니다. 보호자 연결을 켠 경우에만 약 이름·복용 시간·복용 여부가 연결된 가족에게만 공유되고, 서버 기록은 14일 뒤 자동 삭제됩니다.

  • 결제

    App Store 인앱 결제(1회)라 결제 정보는 Apple이 처리합니다. 같은 Apple ID라면 새 기기에서 구매 복원이 됩니다.

  • 안정성

    iOS 알림 개수 제한(64개)을 고려해 반복 알림으로 설계해, 약이 많아도 알림이 빠지지 않습니다. 핵심 로직은 자동 테스트 46개로 검증합니다.

  • 면책

    MediRemind는 의료 기기가 아니며, 복약 알림은 의사·약사의 지시를 대신하지 않습니다. 홍보물에 "치료", "의료용" 같은 표현은 쓰지 마세요.
