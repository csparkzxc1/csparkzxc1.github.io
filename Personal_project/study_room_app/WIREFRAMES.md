# 원장 앱 화면 명세 (v0.1)

**문서 목적**: MVP 기능 정의서 §5.1에 정의된 6개 탭의 화면 흐름·컴포넌트·상태를 명세. 디자이너/개발자 공용 스펙.

**대상**: 원장 앱 (iOS + Android, React Native). 학부모 앱은 MVP에서 제외.

**표기**: `[버튼]`, `<입력>`, `《화면이름》`, `→` 전이.

-----

## 1. 네비게이션 구조

하단 탭 5개 + 우상단 설정 진입.

```
┌─────────────────────────────────────┐
│  상단바: 공부방명          [⚙설정]  │
├─────────────────────────────────────┤
│                                     │
│           본문 영역                  │
│                                     │
├─────────────────────────────────────┤
│ [오늘] [학생] [반] [출결] [정산]    │
└─────────────────────────────────────┘
```

-----

## 2. 《오늘》 홈

### 2.1 목적

원장이 앱을 켜자마자 **지금 해야 할 일**이 보여야 한다.

### 2.2 레이아웃

```
┌─────────────────────────────────────┐
│ 2026년 4월 17일 (금)                │
│                                     │
│ ┌─────────────────────────────┐     │
│ │ 오늘 수업 현황              │     │
│ │  ● 등원 대기: 8명           │     │
│ │  ● 수업 중:  12명           │     │
│ │  ● 하원 완료: 2명           │     │
│ │  ● 결석:      0명           │     │
│ └─────────────────────────────┘     │
│                                     │
│ [+ 일괄 체크인 (반 선택)]           │
│                                     │
│ ─ 반별 등원 현황 ──────────────     │
│ ▸ 초3 월수금 (16:00) 5/7 등원       │
│   [▶ 체크인 시작]                   │
│ ▸ 초5 화목 (17:30) 0/6 등원         │
│                                     │
│ ─ 이번 달 요약 ────────────────     │
│  예상 매출    2,640,000원           │
│  미수금       320,000원 (2건)       │
│  평균 출석률  94%                   │
└─────────────────────────────────────┘
```

### 2.3 주요 컴포넌트

- **TodayStatusCard**: 4개 카운트 (등원 대기/수업 중/하원/결석)
  - 카운트는 오늘 0시 기준 `attendance_record` 집계
- **ClassRoomRow**: 반 1개당 1행. 탭 → 체크인 화면
- **MonthSummaryCard**: 당월 `invoice` 집계, 탭 → 《정산》

### 2.4 상태/엣지케이스

- 오늘 수업이 없는 요일 → "오늘은 수업일이 아닙니다. 쉬는 날 🌿"
- 온보딩 미완료 (학생 0명) → 《학생》 등록 유도 배너 고정
- 미수금 0건 → "이번 달 모두 수납 완료" 배지

## 3. 《학생》 탭

### 3.1 목적

학생 CRUD. 온보딩의 핵심 화면 (KPI: 가입 후 7일 내 10명 등록 60%+).

### 3.2 목록 화면

```
┌─────────────────────────────────────┐
│ 학생 (22명)            [🔍] [+등록] │
├─────────────────────────────────────┤
│ <검색: 이름 또는 학부모 번호>       │
│                                     │
│ 필터: [전체] [초3 월수금] [초5 화목]│
│                                     │
│ ─ 김민서 (초3)                      │
│    월 수강료 180,000원  출석률 96%  │
│    반: 초3 월수금                   │
│ ─ 박지훈 (초5)                      │
│    월 수강료 220,000원  출석률 88%  │
│    반: 초5 화목                     │
│ ...                                 │
└─────────────────────────────────────┘
```

### 3.3 등록/수정 폼

```
┌─────────────────────────────────────┐
│ ← 학생 등록                 [저장]  │
├─────────────────────────────────────┤
│ 이름*         <김민서              > │
│ 학년          <3학년 ▼             > │
│ 월 수강료*    <180,000              > 원 │
│                                     │
│ ─ 학부모 연락처 (최소 1개) ────     │
│ ① 엄마  <010-1234-5678   > [대표 ✓]│
│   [+ 연락처 추가]                   │
│                                     │
│ ─ 반 배정 ────────────────────     │
│ [초3 월수금 ✓] [초5 화목  ] ...     │
│                                     │
│ ─ 형제 관계 ──────────────────     │
│ <형제 학생 선택 ▼> (선택사항)       │
│                                     │
│ 등록일*       <2026-04-17          > │
└─────────────────────────────────────┘
```

### 3.4 검증 규칙

- 이름: 1~50자, 필수
- 전화번호: 한국 휴대폰 형식 (`^010-?\d{4}-?\d{4}$`), 1개 이상 필수
- 월 수강료: 1,000~2,000,000 정수
- 저장 후 → 학부모에게 "등록 완료" 알림톡 자동 발송 (토글로 끌 수 있음)

## 4. 《반》 탭

### 4.1 목록 + 시간표

```
┌─────────────────────────────────────┐
│ 반 관리                     [+ 반]  │
├─────────────────────────────────────┤
│ ▸ 초3 월수금 (영어)                 │
│     월/수/금 16:00~17:30            │
│     학생 7명                        │
│     [✎ 수정] [🗑 삭제]              │
│                                     │
│ ▸ 초5 화목 (영어)                   │
│     화/목 17:30~19:00               │
│     학생 6명                        │
└─────────────────────────────────────┘
```

### 4.2 반 생성/수정

```
┌─────────────────────────────────────┐
│ ← 반 등록                   [저장]  │
├─────────────────────────────────────┤
│ 반 이름*      <초3 월수금          > │
│ 과목          <영어 ▼              > │
│                                     │
│ ─ 시간표 ────────────────────       │
│ □월  <16:00> ~ <17:30>              │
│ □화                                 │
│ ■수  <16:00> ~ <17:30>              │
│ □목                                 │
│ ■금  <16:00> ~ <17:30>              │
│ □토  □일                            │
│                                     │
│ ─ 학생 배정 ──────────────────      │
│ [김민서 ✓] [박지훈  ] [이수빈 ✓]... │
└─────────────────────────────────────┘
```

### 4.3 엣지케이스

- 학생이 속한 반 삭제 시도 → 모달: "이 반에 학생 7명이 있습니다. 먼저 이동하세요" / [취소]만 노출
- 같은 요일에 시간 중복 → 경고만, 저장은 허용

## 5. 《출결》 탭

### 5.1 일별 체크인 화면

가장 많이 쓰는 화면. 속도가 생명.

```
┌─────────────────────────────────────┐
│ < 2026-04-17 (금) >        [달력]   │
├─────────────────────────────────────┤
│ 반: [초3 월수금 ▼]                  │
│ 수업 16:00~17:30                    │
│                                     │
│ ┌────────────────┐ ┌─────────────┐  │
│ │ 김민서         │ │ 박지훈      │  │
│ │ (탭=등원)      │ │ 15:58 등원  │  │
│ │                │ │  [하원]      │  │
│ └────────────────┘ └─────────────┘  │
│ ┌────────────────┐ ┌─────────────┐  │
│ │ 이수빈         │ │ 최도윤      │  │
│ │ (탭=등원)      │ │ 16:02 등원  │  │
│ │                │ │  [하원]      │  │
│ └────────────────┘ └─────────────┘  │
│                                     │
│ [🚫 결석 처리]   [✓ 일괄 하원]     │
└─────────────────────────────────────┘
```

### 5.2 원터치 체크인 UX

- **미체크 카드 탭** → 즉시 `check_in_at = now()` 기록, 카드가 녹색으로 애니메이션 + 알림톡 발송
- **등원 완료 카드 탭** → 하원 처리 확인 모달
- **길게 누르기** → 메뉴: [결석으로 변경] [메모 추가] [시각 수정]

### 5.3 결석 처리 모달

```
┌─────────────────────────────────────┐
│ 김민서 결석 처리                    │
├─────────────────────────────────────┤
│ 사유*                               │
│  ( ) 개인사정                       │
│  (●) 병결                           │
│  ( ) 통보없음                       │
│  ( ) 기타                           │
│                                     │
│ 메모  <감기로 오늘 쉽니다 (엄마)  >  │
│                                     │
│ ☑ 학부모에게 결석 알림 보내기       │
│                                     │
│       [취소]          [확인]        │
└─────────────────────────────────────┘
```

### 5.4 과거 기록 조회/수정

- 기본: 오늘
- 날짜 선택기로 최근 30일까지 이동 가능 (31일 이상 → 수정 버튼 비활성, 조회만)
- 수정 시 알림톡은 **재발송하지 않음** (학부모 혼란 방지)

```
├─────────────────────────────────────┤
│ 기본 수강료          +180,000원     │

│   · 4/3 병결                        │
│   · 4/10 개인사정                   │
│ 형제 할인 (둘째)      -18,000원     │
│ ─────────────────────────────       │
│ 청구 금액             152,000원     │
│                                     │
│ 상태: 미수                          │
│ [💵 수납 완료 (현금)]               │
│ [🏦 수납 완료 (계좌이체)]           │
│ [📨 알림톡 재발송]                  │
│ [📄 PDF 저장]                       │
└─────────────────────────────────────┘
```

### 6.3 정산 생성 흐름

1. 월 마지막 주 월요일 → 《오늘》에 "이번 달 정산서 준비" 배너
2. [정산서 생성] → 서버가 모든 active 학생에 대해 `invoice` 생성
3. 미리보기 → [확정 및 일괄 발송] 클릭 시 알림톡 발송
4. 발송 실패 건은 상단 배너로 재시도 유도

## 8. 온보딩 플로우 (가입 직후)

KPI 직결: **가입 후 7일 내 학생 10명 등록 60%+**.

```
1. 전화번호 인증
   <010-XXXX-XXXX>  [인증번호 받기]
2. 공부방 이름 입력
3. 첫 반 만들기 (예시 자동 제안: "초3 월수금")
4. 첫 학생 3명 등록 (빠른 입력: 이름+번호만)
5. 《오늘》 진입, "체크인 연습해보기" 툴팁
```

건너뛰기 허용. 건너뛰면 《오늘》 상단에 "3단계 남음" 진행 뱃지 유지.

## 9. 핵심 상호작용 원칙

1. **1탭으로 끝난다**: 등원 체크는 다이얼로그 없이 즉시 반영
2. **취소는 3초 이내**: 방금 한 체크인은 스낵바 [실행취소]로 복구
3. **알림톡은 선택 가능**: 모든 자동 발송 액션은 토글 노출
4. **날짜는 항상 명시**: 타임존 혼동 방지 위해 상단 상시 표기
5. **오프라인 내구성**: 체크인은 로컬 큐에 먼저 쌓고 서버 동기화 (알림톡은 온라인일 때만 발송)
